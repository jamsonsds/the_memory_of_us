# The Memory of Us

A Next.js project using the App Router with TypeScript and Tailwind CSS.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project structure

```text
app/
  page.tsx
  login/page.tsx
  memories/page.tsx
  gallery/page.tsx
  future/page.tsx
  messages/page.tsx
components/
lib/
styles/
```
